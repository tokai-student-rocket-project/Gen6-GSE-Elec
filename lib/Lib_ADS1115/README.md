# Lib_ADS1115

Adafruitの[Adafruit_ADS1X15](https://github.com/adafruit/Adafruit_ADS1X15)ライブラリを、初心者でも簡単に扱えるようにしたラッパーライブラリです。

## 概要

ADS1115は16ビットの高精度なアナログ・デジタル変換器（ADC）です。このライブラリを使うことで、センサなどからのアナログ電圧を簡単に読み取ることができます。

### 特徴
- 複雑な設定を隠蔽し、直感的な関数名で操作可能
- 読み取った生データ（デジタル値）を自動で **電圧(V)** に変換する機能を搭載
- 電圧測定範囲（ゲイン）を0〜5の数字で簡単に設定可能

## 依存ライブラリ
このライブラリを使用するには、以下のライブラリがインストールされている必要があります。
- [Adafruit ADS1X15](https://github.com/adafruit/Adafruit_ADS1X15)

## 使い方 (サンプルコード)

```cpp
#include <Arduino.h>
#include "Lib_ADS1115.hpp"

// ADS1115のインスタンスを作成
Lib_ADS1115 adc;

void setup() {
  Serial.begin(115200);

  // 初期化 (I2Cアドレスはデフォルトの0x48)
  if (!adc.init()) {
    Serial.println("ADS1115の初期化に失敗しました。配線を確認してください。");
    while (1); // 失敗したらここでストップ
  }
  Serial.println("ADS1115の初期化に成功しました！");

  // 測定できる電圧の最大範囲を設定 (0: ±6.144V)
  // よく使う3.3Vや5Vを測る場合は0を設定しておくのが安全です。
  adc.setVoltageRange(0); 
}

void loop() {
  // チャンネル0 (A0ピン) の電圧を読み取る
  float voltageA0 = adc.readVoltage(0);
  
  // シリアルモニタに出力
  Serial.print("A0の電圧: ");
  Serial.print(voltageA0);
  Serial.println(" V");

  delay(1000); // 1秒待機
}
```

## APIリファレンス（使える関数一覧）

### `bool init(uint8_t i2cAddress = 0x48)`
ADS1115の初期化を行います。`setup()`の中で必ず1回呼んでください。
- **引数:** `i2cAddress` (省略可能) - I2Cアドレス。デフォルトは `0x48` です。ADDRピンをGNDに繋いでいる場合は変更不要です。
- **戻り値:** 初期化に成功すれば `true`、失敗すれば `false` を返します。

### `float readVoltage(uint8_t channel)`
指定したチャンネルの電圧を **ボルト(V)単位** で直接読み取ります。面倒な計算は不要です。
- **引数:** `channel` - 読み取るピンの番号 (0 〜 3)
- **戻り値:** 電圧値 (例: 3.3V なら `3.30` が返ってきます)

### `int16_t readRaw(uint8_t channel)`
指定したチャンネルの **生のデジタル値** を読み取ります。自分で計算したい場合などに使います。
- **引数:** `channel` - 読み取るピンの番号 (0 〜 3)
- **戻り値:** -32768 〜 32767 のデジタル値

### `void setVoltageRange(uint8_t rangeIndex)`
測定する電圧の最大範囲（ゲイン）を設定します。測りたい電圧の最大値に最も近い（かつ超えない）範囲を選ぶと、より正確（高分解能）な値が取得できます。
- **引数:** `rangeIndex` - 以下の0〜5の数字を指定します。
  - `0` : ±6.144V (デフォルト。最も広い範囲を測れます)
  - `1` : ±4.096V
  - `2` : ±2.048V
  - `3` : ±1.024V
  - `4` : ±0.512V
  - `5` : ±0.256V (狭い範囲しか測れませんが、微小な変化を捉えられます)
