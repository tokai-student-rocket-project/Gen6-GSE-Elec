# Lib_EKF

## 概要
AHRS（Attitude and Heading Reference System：姿勢方位基準装置）用の、クォータニオンベースの拡張カルマンフィルタ（EKF）ライブラリです。ジャイロスコープ、加速度計、磁力計のデータを融合し、姿勢（クォータニオン、オイラー角）とジャイロバイアスを推定します。

## アルゴリズム
この実装は、姿勢推定のための標準的なEKFの定式化に基づいています。特に以下の文献を参考にしています：
*   **Sabatini, A. M. (2006)**. "Quaternion-based extended Kalman filter for determining orientation by inertial and magnetic sensing." *IEEE Transactions on Biomedical Engineering*, 53(7), 1346-1356. [IEEE Xplore](https://ieeexplore.ieee.org/document/1643403)

状態ベクトル（7要素）:
*   クォータニオン ($q_0, q_1, q_2, q_3$)
*   ジャイロバイアス ($b_x, b_y, b_z$)

## 使い方

### インクルード
```cpp
#include "Lib_EKF.hpp"
```

### 初期化
```cpp
EKF ekf;
void setup() {
    ekf.begin(100.0f); // サンプリング周波数 (Hz)
}
```

### 更新ループ
各ループで新しいセンサーデータを使用して `update` を呼び出します。
*   Gyro: 度/秒 (deg/s)
*   Accel: m/s^2 または G (方向が重要)
*   Mag: uT または 生データ

```cpp
void loop() {
    // データを取得
    float gx, gy, gz; // ジャイロ (deg/s)
    float ax, ay, az; // 加速度
    float mx, my, mz; // 地磁気

    ekf.update(gx, gy, gz, ax, ay, az, mx, my, mz);

    // 姿勢を取得
    float roll = ekf.getRoll();
    float pitch = ekf.getPitch();
    float yaw = ekf.getYaw();
}
```

## パラメータ調整
EKFの性能は、プロセスノイズ共分散行列（Q）と観測ノイズ共分散行列（R）のパラメータ設定に大きく依存します。

### ノイズパラメータの意味
*   **Q_angle**: 姿勢（クォータニオン）のプロセスノイズ。  
    *   **大きくすると**: ジャイロの積分をあまり信用せず、加速度・地磁気による補正を強く反映します。応答は速くなりますが、ノイズが乗りやすくなります。
    *   **小さくすると**: ジャイロの積分をより信用します。滑らかになりますが、加速度・地磁気への収束（ドリフト補正）が遅くなります。
*   **Q_bias**: ジャイロバイアスの変動（ランダムウォーク）のプロセスノイズ。
    *   **大きくすると**: バイアスの変化に素早く追従しますが、静止時でもバイアス推定値がふらつく可能性があります。
    *   **小さくすると**: バイアス推定が安定的になります。温度変化などでバイアスが急変した場合の追従は遅れます。
*   **R_accel**: 加速度計の観測ノイズ。
    *   **大きくすると**: 加速度計の値をあまり信用しません（振動に強くなりますが、重力方向への補正が遅れます）。
    *   **小さくすると**: 加速度計の値を強く信用します（水平出しは速いですが、機体の振動や急加速の影響を受けやすくなります）。
*   **R_mag**: 磁力計の観測ノイズ。
    *   **大きくすると**: 磁力計の値をあまり信用しません（磁気外乱に強くなりますが、方位の補正が遅れます）。
    *   **小さくすると**: 磁力計の値を強く信用します（方位出しは速いですが、周囲の磁気環境の変化に敏感になります）。

### 調整の目安
デフォルト値は一般的なMEMSセンサ向けに設定されていますが、実際の環境に合わせて調整してください。
```cpp
// 設定例
ekf.Q_angle = 0.001f;
ekf.Q_bias = 0.003f;
ekf.R_accel = 0.05f;  // 振動が多い環境では大きくする (例: 0.1 ~ 0.5)
ekf.R_mag = 0.05f;    // 磁気歪みが大きい環境では大きくする
```
