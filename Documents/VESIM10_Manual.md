# VESIM10 圧力センサ・システム運用マニュアル

このドキュメントでは、Gen6-GSE で使用されている圧力センサ `VESIM10` の仕組み、設定方法、および実機がない状態でのテスト（シミュレーション）方法について解説します。

---

## 1. システム概要
`VESIM10` は、圧力を電流（4mA ～ 20mA）として出力するセンサです。これをマイコンで読み取るために、サテライトコントローラー（SatelliteController）で電圧に変換し、その値をランチコントローラー（LaunchController）と同期しています。

### 信号変換の流れ
1. **圧力 (MPa)**: センサが物理的な圧力を感知。
2. **電流 (mA)**: 4mA(0MPa) ～ 20mA(定格) の電流を出力。
3. **電圧 (V)**: シャント抵抗（240Ω）を通して電圧に変換。
4. **デジタル値**: マイコンのADC（10bit: 0～1023）で読み取り。
5. **計算**: プログラム内で電流値(mA)を算出し、さらに圧力値(MPa)へ変換。

---

## 2. ハードウェア仕様（初心者向け）
### シャント抵抗
プログラム内で `240.0` (Ω) として定義されています。
- **なぜ必要か？**: マイコンは「電流」を直接測るのが苦手で、「電圧」を測るのが得意だからです。抵抗を通すことで、電流を電圧（$V = I \times R$）に変換しています。

### 5Vシステム
この基板は 5V で動作しています。ADCの分解能は 10ビット（1024段階）です。
- $1ステップ = 5.0V / 1024 \approx 4.88mV$

---

## 3. 計算式 (Mathematical Formulas)
ADC値から圧力値(MPa)を算出するための詳細な計算プロセスは以下の通りです。

### 3.1 ADC値 $\rightarrow$ 電流(mA)
マイコンが読み取った0～1023の値を、まず電流値に変換します。

$$V_{in} = \frac{ADC\_Value \times 5.0}{1024} [V]$$
$$I [mA] = \frac{V_{in}}{R_{shunt} (240.0)} \times 1000$$

### 3.2 電流(mA) $\rightarrow$ 圧力(MPa)
センサの出力仕様（4-20mA）に基づき、電流値から圧力を算出します。

$$P [MPa] = \frac{FullScale}{16.0} \times (I - 4.0)$$

- **$I = 4.0mA$ のとき**: $P = 0 [MPa]$
- **$I = 20.0mA$ のとき**: $P = FullScale [MPa]$

> [!TIP]
> ライブラリ内部では、計算の高速化のために $y = ax + b$ の形に整理して保持しています。
> - $a = FullScale / 16.0$
> - $b = - (FullScale / 4.0)$
>
> 実際のコード： `return _a * (current_mA - _offsetCurrent_mA) + _b;`

## 4. ソフトウェア設定 (Configuration)
センサの定格容量（Full Scale）や校正係数を管理する仕組みです。

### 基本的な設定
`LaunchController.cpp` の定数値を変更することで設定を行います。

```cpp
// LaunchController.cpp
namespace n2o {
// --- キャリブレーション設定 ---
const float SENSOR_FS_MPa = 10.0f;                     // 定格圧力
const float CALIB_SLOPE_A = SENSOR_FS_MPa / 16.0f;     // 傾き (理論値は FS/16)
const float CALIB_INTERCEPT_B = -CALIB_SLOPE_A * 4.0f; // 切片 (理論値は -a*4)
}
```

### 同期の仕組み
1. ランチコントローラー（Launch）が起動時に `SENSOR_CALIB_COEFF_SYNC` パケットを送信。
2. サテライトコントローラー（Satellite）が受信し、自身の `VESIM10` インスタンスの設定（傾き $a$ と切片 $b$）を更新。
これで、機体側のコードを書き換えることなくセンサ特性の変更に対応できます。

## 5. シミュレーションモード (Dummy Mode)
実機のセンサや圧力源がない場合でも、通信や表示をテストできます。

### 使い方
`LaunchController.cpp` から擬似的な電流値を送ります。

```cpp
// 12.0mA をシミュレート（定格10MPaの場合、5.0MPaと表示されるはずです）
communication::sendSensorDummyCurrent(12.0f);

// 通常モード（実センサ読み取り）に戻す
communication::sendSensorDummyCurrent(0.0f);
```

### 特徴
- **オフセットの自動除去**: シミュレートされた電流値（4mAなど）に対して、現場で発生している物理的な校正オフセットを適用しません。これにより、常に理想的な理論値（4mA = 0.0MPa）でロジックのテストが可能です。

---

## 6. 主要な関数リファレンス
### `VESIM10` クラス (lib/VESIM10)
- `getCurrent_mA()`: 現在の電流値を計算。
- `getPressure_MPa()`: 現在の圧力値を計算。
- `setCalibration(float a, float b)`: 校正係数を直接設定。
- `setDummyCurrent(float mA)`: テスト用の値を注入。
- `calibrateBlocking(uint8_t count)`: 現場でのゼロ点オフセットを取得。

## 7. 遠隔モニタリング (Remote Monitoring)
実験中に安全な場所からセンサの状態を確認する機能です。

### シリアルモニタでの確認
操作卓（Launch）をPCに接続し、シリアルモニタを開くと以下のように出力されます。
```text
>VESIM10 Current: 4.12 mA
```
この値は機体側で測定された生の電流値であり、Excelでの校正データ作成にそのまま使用できます。

---

## 8. 校正フロー
「センサ固有の感度」と「現場のノイズ・ゼロ点」を切り分けて管理する、推奨される運用フローです。

### 手順1：事前試験で「傾き」を確定させる
高圧ガス試験を行い、標準圧力計と電流値をプロットします。

#### Excelでの算出手順：
1. **データの記録**: ExcelのA列に「実測電流値(mA)」（上記「遠隔モニタリング」の値を使用）、B列に「マスタ圧力計の値(MPa)」を入力します。
2. **グラフの作成**: 散布図を作成し、「近似曲線の表示」で数式を出力します。
3. **係数の抽出**: グラフの式 `$y = ax + b$` の、
   - **傾き `$a$`** の値を `LaunchController.cpp` の `CALIB_SLOPE_A` に記入します。
   - ※切片 `$b$` は手順2で自動補正されるため、理論値のままでも運用可能です。

### 手順2：現場で「ゼロ点」を確定させる
現場で電源を入れると、5秒後に自動的に「ゼロ点校正要求」が送信されます。
- **重要**: この時、配管内が大気開放（0MPa）であることを確認してください。
- これにより、その瞬間の電流値を新しい「基準の4mA（0MPa点）」としてオフセットを設定します。

### メリット
- **高精度**: 個体ごとの傾きの違い（感度）を事前試験で反映できます。
- **柔軟性**: 現場ごとのノイズや電圧差（ゼロ点）は、起動時の自動処理でリセットされるため、常に正確な0.0MPaから測定を開始できます。

## 9. FAQ
**Q. 7SEGディスプレイが「- -」のままです**

A. 電流値が `0.1mA` 未満の場合、センサ未接続またはエラーと判断して表示をクリアする仕様になっています。

**Q. シミュレーションだと0.0MPaにならない**

A. 実機運用モードとシミュレーションモードが正しく切り替わっていない可能性があります。`sendSensorDummyCurrent(0.0f)` を送って実機モードに戻すか、`VESIM10.cpp` の `_isDummyMode` のフラグを確認してください。
