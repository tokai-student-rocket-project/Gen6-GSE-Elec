# PlatformIO 導入・書き込みガイド (Gen6 GSE System)

本ドキュメントは，**PlatformIO を初めて使う人** が，開発環境の導入から Gen6 GSE のマイコンへプログラムを書き込むまでを一通り行えるようにまとめた手順書です．上から順番に進めれば書き込みまで到達できます．

## 1. 全体の流れ

```mermaid
flowchart LR
    A[VSCode を<br>インストール] --> B[PlatformIO を<br>インストール]
    B --> C[プロジェクトを<br>開く]
    C --> D[環境 env を<br>選ぶ]
    D --> E[ビルド]
    E --> F[書き込み]
    F --> G[シリアルモニターで<br>確認]
```

最初に覚えておく用語は次の 3 つだけです．

| 用語 | 意味 |
| --- | --- |
| **ビルド (Build)** | 書いたプログラムを，マイコンが実行できる形に変換すること．エラーがあればここで見つかる |
| **書き込み (Upload)** | ビルドしたプログラムを USB 経由でマイコンに送り込むこと |
| **環境 (env)** | 「どの基板に，どのソースファイルを書き込むか」の設定をまとめたもの．[`platformio.ini`](../platformio.ini) に定義されている |

> [!NOTE]
> PlatformIO は Arduino IDE と同じ Arduino 言語でプログラムを書けます．違いは，ライブラリを自動でダウンロードしてくれる点と，1 つのプロジェクトで複数の基板を扱える点です．

| 用意するもの | 備考 |
| --- | --- |
| PC | Windows / macOS / Linux のいずれでも可 |

| [Git](https://git-scm.com/) | プロジェクトの取得と，サテライトノード用プラットフォームの取得に使用 |

## 3. VSCode と PlatformIO のインストール

### Step 1: VSCode をインストールする

1. [Visual Studio Code 公式サイト](https://code.visualstudio.com/) からインストーラーをダウンロードします．
2. インストーラーを実行し，基本的に初期設定のまま「次へ」で進めます．

### Step 2: PlatformIO IDE 拡張機能をインストールする

1. VSCode を起動します．
2. 左端のアイコン列から **拡張機能** (四角が 4 つ並んだアイコン) をクリックします．ショートカットは `Ctrl + Shift + X` です．
3. 検索欄に `PlatformIO IDE` と入力します．
4. 発行元が **PlatformIO** のものを選び，**インストール** をクリックします．
5. インストールが終わるまで待ちます．右下に進行状況が表示され，数分かかることがあります．
6. 「Reload Now」や再起動を求める表示が出たら，VSCode を再起動します．

左端のアイコン列に **アリの顔のアイコン (PlatformIO)** が追加されていれば成功です．

> [!TIP]
> Python を別途インストールする必要はありません．PlatformIO が必要なものを自動で用意します．

## 4. プロジェクトを取得して開く

### Step 1: プロジェクトを取得する

ターミナル (Windows の場合は PowerShell) を開き，保存したいフォルダに移動してから次のコマンドを実行します．

```bash
git clone https://github.com/tokai-student-rocket-project/Gen6-GSE-Elec.git
```

> [!TIP]
> Git に慣れていない場合は，GitHub のページで **Code → Download ZIP** からダウンロードして展開する方法でも構いません．

### Step 2: VSCode で開く

1. VSCode のメニューから **ファイル → フォルダーを開く** を選びます．
2. `Gen6-GSE-Elec` フォルダを選択します．

> [!IMPORTANT]
> 必ず **`platformio.ini` が直下にあるフォルダ** (`Gen6-GSE-Elec`) を開いてください．`src` など中のフォルダを開いたり，1 つ上のフォルダを開いたりすると，PlatformIO がプロジェクトとして認識しません．

初めて開いたときは，PlatformIO が必要なツールやライブラリを自動でダウンロードします．右下の表示が消えるまで待ってください．

## 5. 書き込む環境 (env) を選ぶ

このプロジェクトには複数の基板・バージョンのプログラムが入っているため，**どれを書き込むかを最初に選ぶ** 必要があります．

### 環境の一覧

| 環境名 | 書き込み先の基板 | マイコン | ソースファイル | 書き込み方法 |
| --- | --- | --- | --- | --- |
| `Launch` | ランチコントローラー (Gen6 1.0) | ATmega2560 | `src/LaunchController/` | USB |
| `Satellite` | サテライトコントローラー (Gen6 1.0) | ATmega2560 | `src/SatelliteController/` | **ArduinoISP** |
| `Launch2` | ランチコントローラー (Gen6 2.0) | ATmega2560 | `src/LaunchController2.0/` | USB |
| `Satellite2` | サテライトコントローラー (Gen6 2.0) | ATmega2560 | `src/SatelliteController2.0/` | USB |
| `Launch3` | ランチコントローラー (Gen6 3.0) | ATmega2560 | `src/LaunchController3.0/` | USB |
| `Satellite3` | サテライトコントローラー (Gen6 3.0) | ATmega2560 | `src/SatelliteController3.0/` | USB |
| `SatelliteNode` | サテライトノード | XIAO RA4M1 | `src/SatelliteNode/` | USB |

ランチコントローラーとサテライトコントローラーは通信し合うため，**同じバージョン同士** (例: `Launch2` と `Satellite2`) を書き込んでください．

### 環境の選び方

1. VSCode の **画面最下部の青いバー (ステータスバー)** を見ます．
2. `Default (Gen6-GSE-Elec)` と表示されている部分をクリックします．
3. 画面上部に一覧が出るので，書き込みたい環境 (例: `env:Launch2`) を選びます．
4. ステータスバーの表示が `env:Launch2 (Gen6-GSE-Elec)` に変われば完了です．

> [!WARNING]
> `Default` のまま書き込みを行うと，**すべての環境が順番にビルド・書き込みされます**．意図しないプログラムが基板に書き込まれてしまうため，必ず環境を選んでから操作してください．

---

## 6. ビルドする

書き込む前に，まずビルドが通ることを確認します．

1. ステータスバーの **チェックマーク (✓)** をクリックします．
2. 画面下部にターミナルが開き，ビルドが始まります．
3. 最後に `SUCCESS` と表示されれば成功です．

```text
========================= [SUCCESS] Took 12.34 seconds =========================
```

`FAILED` と表示された場合は，ターミナルを上にさかのぼって **`error:`** と書かれた行を探してください．ファイル名と行番号が表示されています．

> [!NOTE]
> 初回のビルドは，ライブラリやコンパイラのダウンロードが入るため数分かかります．2 回目以降は速くなります．

## 7. マイコンに書き込む

> [!CAUTION]
> 書き込み中および書き込み直後はマイコンがリセットされ，出力ピンの状態が一時的に変わります．**電磁弁・点火系統を接続した状態や，充填中・運用中には絶対に書き込みを行わないでください．**

### 7.1 USB で書き込む (ランチ / サテライトコントローラー)

対象: `Launch` `Launch2` `Satellite2` `Launch3` `Satellite3`

1. 基板のハッチを開け，**USB Type-B** ケーブルで PC と基板を接続します．
2. PC が基板を認識していることを確認します ([7.4](#74-com-ポートの確認方法) 参照)．
3. [5 章](#5-書き込む環境-env-を選ぶ) の手順で，書き込みたい環境が選ばれていることを確認します．
4. ステータスバーの **右向き矢印 (→)** をクリックします．
5. ビルドに続いて書き込みが行われ，`SUCCESS` と表示されれば完了です．

書き込み先の COM ポートは PlatformIO が自動で探します．USB 機器を複数つないでいて誤ったポートが選ばれる場合は，[10 章](#10-困ったときは) を参照してください．

### 7.2 USB で書き込む (サテライトノード)

対象: `SatelliteNode`

1. **USB Type-C** ケーブルで PC と XIAO RA4M1 を接続します．
2. 環境 `env:SatelliteNode` を選びます．
3. ステータスバーの **右向き矢印 (→)** をクリックします．

初回は Seeed 社のプラットフォームを Git 経由でダウンロードするため，**Git がインストールされている必要があります**．書き込みに失敗する場合は，XIAO をブートローダーモードに入れてから再度書き込んでください．入れ方は [Seeed Studio 公式 Wiki](https://wiki.seeedstudio.com/getting_started_xiao_ra4m1/) を参照してください．

### 7.3 ArduinoISP で書き込む (`Satellite` のみ)

Gen6 1.0 のサテライトコントローラーは USB からの書き込みができないため，**別の Arduino を書き込み装置 (ArduinoISP) として使います**．

#### Step 1: 書き込み装置を作る

1. Arduino UNO などを PC に接続します．
2. Arduino IDE で **ファイル → スケッチ例 → 11.ArduinoISP → ArduinoISP** を開き，その Arduino に書き込みます．

#### Step 2: 配線する

書き込み装置の Arduino と，サテライトコントローラー基板の ICSP 端子を接続します．基板側の端子位置は [回路図](./Development/CircuitDiagram/) を確認してください．

| 書き込み装置 (Arduino UNO) | サテライトコントローラー (ICSP) |
| --- | --- |
| D10 | RESET |
| D11 | MOSI |
| D12 | MISO |
| D13 | SCK |
| 5V | VCC |
| GND | GND |

#### Step 3: COM ポートを指定して書き込む

この環境は COM ポートを自動で探さないため，**書き込み装置の COM ポートを指定する** 必要があります．ポート番号は [7.4](#74-com-ポートの確認方法) の方法で確認してください．

PlatformIO のターミナル ([9 章](#9-コマンドで操作する場合-cli) 参照) で次のコマンドを実行します．`COM5` の部分は自分の環境に合わせて変更します．

```bash
pio run -e Satellite -t upload --upload-port COM5
```

### 7.4 COM ポートの確認方法

| OS | 確認方法 |
| --- | --- |
| Windows | **デバイス マネージャー → ポート (COM と LPT)** を開く．USB を抜き差しして増減する `COMx` が対象 |
| macOS | ターミナルで `ls /dev/cu.*` を実行する |
| Linux | ターミナルで `ls /dev/ttyUSB* /dev/ttyACM*` を実行する |

PlatformIO からも確認できます．左端の **アリのアイコン → PROJECT TASKS → General → Devices** をクリックすると，接続中のデバイス一覧が表示されます．

## 8. シリアルモニターで動作確認する

マイコンが `Serial.print()` で出力した文字を PC で確認できます．

1. USB ケーブルで PC と基板を接続します．
2. ステータスバーの **電源プラグのアイコン** をクリックします．
3. 画面下部のターミナルに，マイコンからの出力が表示されます．
4. 終了するときは，ターミナルをクリックしてから `Ctrl + C` を押します．

通信速度 (ボーレート) は `platformio.ini` の `monitor_speed = 115200` が自動で使われます．

> [!IMPORTANT]
> シリアルモニターを開いたままだと，COM ポートが使用中になり書き込みに失敗することがあります．別のソフト (Arduino IDE のシリアルモニター，Tera Term など) でポートを開いている場合は，書き込み前に閉じてください．

### ステータスバーのアイコン早見表

| アイコン | 名前 | 動作 |
| --- | --- | --- |
| 家 | Home | PlatformIO のホーム画面を開く |
| ✓ | Build | ビルドする |
| → | Upload | ビルドして書き込む |
| ごみ箱 | Clean | ビルド結果を削除する (動作がおかしいときに使う) |
| 電源プラグ | Serial Monitor | シリアルモニターを開く |
| ターミナル | New Terminal | `pio` コマンドが使えるターミナルを開く |
| `env:...` | 環境の切り替え | 書き込む環境を選ぶ |

## 9. コマンドで操作する場合 (CLI)

ボタン操作の代わりに，コマンドでも同じことができます．

ステータスバーの **ターミナルのアイコン** をクリックして開いたターミナルで実行してください．通常の PowerShell などでは `pio` コマンドが見つからないことがあります．

| コマンド | 説明 |
| --- | --- |
| `pio run -e Launch2` | `Launch2` をビルドする |
| `pio run -e Launch2 -t upload` | `Launch2` をビルドして書き込む |
| `pio run -e Launch2 -t upload --upload-port COM5` | COM ポートを指定して書き込む |
| `pio run -e Launch2 -t clean` | `Launch2` のビルド結果を削除する |
| `pio device list` | 接続中のデバイス (COM ポート) を一覧表示する |
| `pio device monitor -b 115200` | シリアルモニターを開く |

`-e` の後ろには [5 章の環境名](#環境の一覧) を指定します．`-e` を省略するとすべての環境が対象になるため，必ず指定してください．

## 10. 困ったときは

| 症状 | 原因と対処 |
| --- | --- |
| アリのアイコンやステータスバーのボタンが出てこない | `platformio.ini` が直下にあるフォルダを開いているか確認する ([4 章](#4-プロジェクトを取得して開く))．開き直しても出ない場合は VSCode を再起動する |
| ビルドで `No such file or directory` (ライブラリが見つからない) | インターネット接続を確認してから再度ビルドする．直らない場合は Clean (ごみ箱) を実行してからビルドする |
| 書き込みで `could not open port` / `アクセスが拒否されました` | COM ポートが他のソフトに使われている．シリアルモニターや Arduino IDE を閉じる |
| 書き込みで `not in sync` / `timeout` | USB ケーブルが充電専用でないか確認する．別の COM ポートに書き込もうとしていないか確認し，必要なら `--upload-port` でポートを指定する |
| COM ポートが表示されない | USB ケーブルを交換する．Windows で認識しない場合は [FTDI の VCP ドライバ](https://ftdichip.com/drivers/vcp-drivers/) をインストールする |
| 誤ったポートに書き込まれる | 対象以外の USB シリアル機器を抜くか，`--upload-port` でポートを指定する |
| `Satellite` の書き込みに失敗する | この環境は ArduinoISP を使う ([7.3](#73-arduinoisp-で書き込む-satellite-のみ))．配線と `--upload-port` の指定を確認する |
| `SatelliteNode` の初回ビルドに失敗する | Git がインストールされているか確認する．インストール後は VSCode を再起動する |
| 書き込めたが動作がおかしい | 選んだ環境が基板と合っているか，ランチ側とサテライト側で同じバージョンを書き込んでいるか確認する |
| 原因が分からない | Clean (ごみ箱) を実行する．それでも直らない場合はプロジェクト内の `.pio` フォルダを削除してからビルドし直す |
