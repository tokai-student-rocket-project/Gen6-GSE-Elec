# VESIM10 圧力センサ・システム運用マニュアル

このドキュメントでは、Gen6-GSE で使用されている圧力センサ `VESIM10` の仕組み、設定方法、校正手順、および詳細な計測ロジックについて解説します。

---

## 1. システム概要
`VESIM10` は、圧力を電流（4mA ～ 20mA）として出力する産業用センサです。
サテライトコントローラー（SatelliteController）で電圧に変換して読み取り、その計算結果をランチコントローラー（LaunchController）へ送信しています。

### 信号変換の流れ
1.  **圧力 (MPa)**: センサが物理的な圧力を感知。
2.  **電流 (mA)**: 4mA(0MPa) ～ 20mA(定格) の電流を出力。
3.  **電圧 (V)**: シャント抵抗（240Ω）を通して電圧に変換。
4.  **デジタル値**: マイコンのADC（10bit: 0～1023）で読み取り。
5.  **計算部**:
    *   ADC値を電流値(mA)に変換。
    *   1次遅れフィルタ(LPF)によるノイズ除去。
    *   ゼロ点オフセット（現場補正）の適用。
    *   校正係数（$y = ax + b$）による圧力値(MPa)の算出。

---

## 2. ゼロ点校正の重要手順
現場での電圧降下やノイズの影響を排除し、正確に 0.0MPa から計測を開始するための手順です。

> [!IMPORTANT]
> **ゼロ点校正を再度行う（やり直す）場合は、ランチコントローラーの電源を切り、数秒待ってから電源を再投入してください。**
> 
> 理由は、ランチコントローラーが起動してから **5秒後** に、自動で機体（Satellite）に対して「今の値を 0MPa とせよ」という校正要求を送る仕組みになっているためです。

### 手順
1.  配管内を **大気開放（0MPaの状態）** にします。
2.  ランチコントローラーの電源を入れます。
3.  5秒待つと、機体側で自動的に校正が完了します。
4.  操作卓の7SEGディスプレイが `0.0` を示せば準備完了です。

## 3. 計算ロジックの詳細 (Logic Breakdown)
`lib/VESIM10` 内部で行われている処理の詳細です。

### 3.1 ADC値 $\rightarrow$ 生の電流値 $I_{raw}$
マイコンは基準電圧5V、1024段階で電圧を読み取ります。

$$V_{in} = \frac{ADC\_Value \times 5.0}{1024} [V]$$
$$I_{raw} [mA] = \frac{V_{in}}{R_{shunt} (240.0)} \times 1000$$

### 3.2 ノイズ除去 (1次遅れフィルタ)
サンプリングごとの急激な変動を抑えるため、以下のフィルタを適用しています。
現在のフィルタ係数 $k$ は `0.2` に設定されています。

$$I_{filtered} = (1.0 - k) \times I_{old} + k \times I_{raw}$$

### 3.3 ゼロ点オフセットの適用
起動時の校正で取得された「理想の4mAからのズレ」を差し引きます。
※ $I_{offset} = \text{起動時の平均電流} - 4.0mA$

$$I_{effective} = I_{filtered} - I_{offset}$$

### 3.4 最終的な圧力算出
校正係数 $a$（傾き）と $b$（切片）を用いて圧力を出力します。

$$P [MPa] = a \times I_{effective} + b$$

*   **理論値での係数**:
    *   $a = FullScale / 16.0$
    *   $b = - (FullScale / 4.0)$
*   **高精度運用（推奨）**:
    手順8に従い、Excel等で求めた実測の係数を `LaunchController.cpp` に直接入力することで、センサ個体差を吸収できます。

## 4. ソフトウェア設定 (Configuration)
`LaunchController.cpp` の以下の箇所で、使用するセンサの性能を設定します。

```cpp
// LaunchController.cpp
namespace n2o {
  const float SENSOR_FS_MPa = 10.0f;                     // 使用するセンサの最大圧力
  const float CALIB_SLOPE_A = SENSOR_FS_MPa / 16.0f;     // 傾き
  const float CALIB_INTERCEPT_B = -CALIB_SLOPE_A * 4.0f; // 切片
}
```

## 5. シミュレーションモード (Dummy Mode)
実機がない環境でのテスト手順です。

1.  `LaunchController.cpp` 内で `communication::sendSensorDummyCurrent(12.0f)` （例：50%の圧力）を実行。
2.  システム全体が校正を無視し、理想的な 12.0mA として圧力を計算・表示します。
3.  終了時は `0.0f` を送ることで実機モードに戻ります。

---

## 6. 主要な関数リファレンス
- `getCurrent_mA()`: フィルタ適用後の電流値を取得。
- `getPressure_MPa()`: 最終的な圧力(MPa)を取得。
- `calibrateBlocking(count)`: 現場でのゼロ点オフセットを決定（ランチ起動時に自動実行）。

---

## 7. 高精度校正フロー（事前試験）
高圧ガス試験の結果を反映させる手順です。

1.  **データの記録**: 操作卓をPCに繋ぎ、シリアルモニタで `>VESIM10 Current` を確認しながら、標準圧力計の値を記録します。
2.  **Excelプロット**: 横軸に電流(mA)、縦軸に圧力(MPa)をプロットします。
3.  **係数の反映**: 得られた近似式 $y = ax + b$ の $a$ と $b$ を `LaunchController.cpp` に記入して書き込みます。
4.  **仕上げ**: 現場では「起動時の自動ゼロ点校正」に任せることで、温度や配線抵抗によるオフセットを自動で打ち消せます。

## 8. FAQ
**Q. ディスプレイが「- -」のままです**
A. 電流が 0.1mA 未満です。センサが抜けているか、断線しています。

**Q. 計測値が安定しません**
A. グランド(GND)の電位差や、周辺の電磁弁からのノイズを確認してください。必要に応じて `VESIM10.cpp` のフィルタ係数 $k$ を小さく（例：0.1）してください。
