# Temporary / Scratch Files (作業用一時ファイル)

本ディレクトリは、開発や検証、データ抽出時に一時的に作成されたスクラッチスクリプトや一時テキストファイルの退避場所です。

## 保管ファイル
- `cobs.py`: COBS (Consistent Overhead Byte Stuffing) 実装検証用の一時ファイル（`tools/raspi_gse_control/raspi_gse_control.py` に組み込み済み）
- `temp.py`: ソースコード一括整形・置換用のワンタイムスクリプト
- `datasheet.txt`: SP0504S TVSダイオードデータシートのテキストダンプ
- `rk73h_text.txt`: KOA RK73H チップ抵抗データシートのテキストダンプ

※ これらは必要に応じて削除・参照可能です。
